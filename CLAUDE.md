# PSP деньги

Google Apps Script: перенос денег 2026 года из Google-таблицы «PSP-наборы»
в Битрикс24 (сделки воронки PSP, счета, оплаты).

- Код: `Код.js` (весь скрипт), `appsscript.json` (настройки проекта).
- Связь папки с проектом Google — `.clasp.json` (scriptId). В git этот файл не лежит
  (он в `.gitignore`): scriptId у каждого свой, создаётся через `clasp clone <scriptId>`.
- clasp работает под аккаунтом владельца проекта.
- `dryRun` — читает таблицу и Битрикс (общая часть — `buildPlan_`) и пишет листы
  «План переноса» и «Чек-лист для Гулим». В Битриксе ничего не меняет.
- `liveRun` — боевой перенос по плану и ответам Гулим (колонка E чек-листа),
  не больше `LIVE_LIMIT` строк за запуск, всё пишет в лист «Журнал переноса».
  Переключатель `LIVE_DRY` (по умолчанию `true`): пока он включён, в Битрикс ничего
  не пишется. Все записи в Битрикс идут только через `write_()` и `ensureStream_()`.

## Правила

1. **Вебхук — только в свойствах скрипта.** Адрес вебхука Битрикса хранится
   в свойстве скрипта `BITRIX_WEBHOOK` (читается через `webhook_()`).
   Никогда не писать адрес вебхука в код, комментарии, коммиты или CLAUDE.md.
   Так же хранится ID таблицы — в свойстве `SHEET_ID` (читается через `sheetId_()`).
   Реальные телефоны, почты и имена клиентов в код и комментарии не писать.
2. **Перед каждой правкой — коротко объяснить**, что и зачем меняется,
   простыми словами (пользователь только учится).
3. **После правок:** сначала `git commit`, потом `clasp push`.
4. **Всё, что пишет в Битрикс, сначала только в режиме пробного прогона.**
   Любые вызовы, меняющие данные в Битриксе (`*.add`, `*.update`, `*.delete`
   и т. п.), делать только за переключателем пробного прогона, который по
   умолчанию включён: в пробном режиме — лишь показать в таблице, что было бы
   сделано. Боевой запуск — только по явному решению пользователя.

## Команды

- `clasp push` — загрузить локальный код в Google.
- `clasp pull` — скачать код из Google (если правили в браузерном редакторе).
- Если в терминале `clasp` не находится — открыть новое окно терминала
  (папка `%APPDATA%\npm` добавлена в PATH пользователя).
